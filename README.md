# Mini Pokédex

A small Pokémon-themed website for CS4127. Browse eight Pokémon, search by name, filter by type and build a team of up to six. The team is saved in your browser.

## Files

- `index.html` is the page. GitHub Pages looks for this exact name.
- `style.css` holds the colours and layout.
- `script.js` holds the search, filter and team code.

There are no images to upload and no internet connection is needed. Open `index.html` in your browser to try it.

## Put it online with GitHub Pages

1. Make a new public repository on GitHub.
2. Upload `index.html`, `style.css` and `script.js`.
3. In Settings, then Pages, choose the `main` branch and the `/ (root)` folder, then Save.
